## 1. Overview & Research Principles

This directory contains intermediate and final quantitative artifacts generated by executing the committed analytical procedures (`scripts/`) against immutable research inputs (`inputs_frozen/`).

> [!IMPORTANT]
> **Reproducibility Standard:**  
> Files in this directory are **not primary evidence**. Every artifact is fully regenerable via deterministic scripts. Primary sources of truth reside strictly within `inputs_frozen/` and `reference/`.

| Dimension | Primary Evidence (`inputs_frozen/`) | Derived Outputs (`data_derived/`) |
| :--- | :--- | :--- |
| **Provenance** | External deposit snapshot (Zenodo DOI 10.5281/zenodo.21532575) | Algorithmic execution of internal scripts |
| **Mutativity** | Immutable (frozen) | Regenerable via pipeline execution |
| **Modification Policy** | Strict read-only | Overwritten only via re-running procedures |
| **Version Tracking** | Tracked in version control | Gitignored by default; milestone snapshots committed intentionally |

## 4. Version Control & Tracking Policy

Per project governance decisions (`docs/session_log.md`, 2026-08-18):

1. **Default Ignore Rule:** `data_derived/*` is gitignored to avoid tracking transient operational outputs.
2. **Explicit Milestone Tracking:** Verified benchmark datasets and publication milestones are committed deliberately using forced staging (`git add -f`).
3. **Transient Outputs:** Runtime diagnostics (`merge_diagnostics.txt`, `tier_cross_check.txt`) and intermediate merges (`ct_source_all.csv`) remain untracked.

## 5. Reproduction Instructions

To regenerate all derived analytical tables from scratch:

```bash
# Execute analytical pipeline in sequence (standard library)
.venv\Scripts\python.exe scripts/merge_source_data.py
.venv\Scripts\python.exe scripts/build_tier_map.py
.venv\Scripts\python.exe scripts/apply_weights.py
.venv\Scripts\python.exe scripts/precedence_test_weighted.py
.venv\Scripts\python.exe scripts/sensitivity_analysis.py

# Offline ingestion of archived contrast-week audit data
.venv\Scripts\python.exe scripts/ct_artlist_audit.py --contrast
```
